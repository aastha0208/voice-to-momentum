# Candidate roadmap

These are proposals, not implemented features.

1. Validate live Jev on human-reviewed synthetic examples.
2. Preserve original assessments, full probabilities and configuration snapshots in exports.
3. Allow category definitions, impact and follow-up review policies to be edited.
4. Make area and impact correctable with per-field review.
5. Add LLM-assisted item extraction with source quotes and human confirmation.
6. Add commitment-versus-action evidence checks for agent transcripts.
7. Add opt-in integrations only after the core decisions are useful.

Keep the initial release focused on reviewable triage; do not imply that routing labels execute external work.
