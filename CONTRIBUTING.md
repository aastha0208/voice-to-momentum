# Contributing

Start an issue describing the user problem, current behavior, expected behavior and a synthetic reproduction. Do not include API keys or private customer notes.

Keep demo and live behavior distinguishable. Preserve uncertainty and fallback options. Document rubric changes and evaluate them on fixed examples plus fresh cases. Run `node --check worker/index.js` and exercise the local app before proposing changes. Check restore, approval, thresholds, clearing, CSV and custom labels when changing review logic.

There is no selected open-source license yet; discuss reuse and contribution terms with the maintainer before substantial contributions.
